# Support

Use the GitHub issue forms for reproducible bugs and focused feature requests:

- [Report a bug](https://github.com/antiburn/antiburn/issues/new?template=bug.yml)
- [Request a feature](https://github.com/antiburn/antiburn/issues/new?template=feature.yml)

Search existing issues first. Include synthetic examples only. Do not include
credentials, transcripts, repository names, or private file paths.

The project does not provide a guaranteed response time or private product
support. For security vulnerabilities, do not open an issue. Follow the
[security policy](SECURITY.md) instead.

The [support matrix](docs/support.md) documents supported agents, platforms,
data locations, network behavior, and known limits.
