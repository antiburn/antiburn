# Governance

Cadence AI (Vic) Pty Ltd is the project steward. The company appoints
maintainers and grants repository permissions based on their responsibilities.

Maintainers set project direction, review contributions, manage releases, and
enforce the code of conduct. Decisions favor user privacy, local processing,
bounded resource use, and compatibility with documented agent data formats.

Contributions use GitHub issues and pull requests. Maintainers seek consensus
where practical. The company makes the final decision when consensus is not
possible or a decision affects product direction, legal obligations, security,
or release safety.

Maintainers can request changes, defer work, or decline changes that do not fit
the project scope. All commits require a Developer Certificate of Origin
sign-off. See [CONTRIBUTING.md](CONTRIBUTING.md) for the review and validation
requirements.

Security reports use the private process in [SECURITY.md](SECURITY.md).
Published releases follow the review and immutability process in the
[release guide](docs/runbooks/release.md).
